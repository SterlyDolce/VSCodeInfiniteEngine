# Native game schema example

This compact project demonstrates a valid Infinite Engine project, scene,
typed asset reference, native environment, native camera, and visual-script
execution. It intentionally contains no DOM, Canvas 2D, SVG, or custom renderer.

## Run

1. Open this directory as the game workspace in the Extension Development Host.
2. Open `Scenes/Main.iescene` in the Infinite Scene Editor.
3. Start play mode.
4. Confirm the environment and camera load and the Infinite Engine output
   contains `Native example started`.

The example is deliberately minimal. Geometry and material authoring should be
performed through their editors because generated payloads are not useful as
hand-written documentation fixtures.
